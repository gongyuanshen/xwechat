## 验收边界

冻结后端与界面使用可丢弃的合成数据；OCR 检索使用预先构造的缓存。这些检查没有读取真实微信资料、执行真实 OCR／模型推理、发送微信消息，或实际操作安装向导。事项系统通知的真实弹出、用户完整资料和不同 Windows 设备仍需分别验收。

本次产物沿用现有未签名构建配置。包结构和服务验收不能替代操作系统签名信誉或安装向导验收。
